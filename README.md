# Elevvo


This project was developed for Elevvo as a responsive front-end web solution.  
It provides a clean, modern, and interactive user experience using HTML,CSS, and JavaScript.  

---

## ✨ Features  

* Fully responsive layout (mobile, tablet, desktop)  
* Modern styling with Tailwind CSS  
* Dynamic interactivity powered by JavaScript
* Clean and semantic HTML5 structure  
* Cross-browser compatibility  

---

## 🛠 Tech Stack  

| Technology      | Purpose                          |
|-----------------|----------------------------------|
|     HTML5       | Page structure & semantic layout |
|  Tailwind CSS   | Styling & responsive design      |
|   JavaScript    | Interactivity & logic            |
